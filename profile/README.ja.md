# Curio

### AI エージェントのためのデザインスタイルライブラリ。

スタイルを選んで、`DESIGN.md` を AI に転送するだけ。サイトもスライドもレポートも、数秒で仕上がります。

Curio は、デザインの潮流、ブランド、文化的伝統——バウハウス、Stripe、北斎の浮世絵、メンフィス、アール・デコ、ペルシャ絨毯など数千のスタイル——を、完全で機械可読なデザインシステムにまとめています。それぞれがトークン化され、実例が付属し、AI エージェントがいま作っているものにそのまま適用できるように書かれています。

## デザインシステムの中身

すべてのスタイルは 1 つの `DESIGN.md` として提供され、エージェントはこのファイルを最初から最後まで読むだけで済みます。

- **トークン** — パレット、タイプスケール、余白、角丸、影、モーション。散文ではなく構造化データです。
- **コンポーネント** — ボタン、カード、ナビゲーション、フォーム、データ表示がこのスタイルでどう見えるか。
- **由来とルール** — スタイルの出自、こだわり、そして決してやらないこと。
- **CSS テクニック** — グレイン、ガラス、グラデーション、グリッドなど、「らしさ」を作る手法。
- **6 つの実例** — 記事、ダッシュボード、料金ページ、3 枚組のスライド。適用後の姿を先に確かめられます。

背景にある物語を先に知りたい場合は、[スタイルアカデミー](https://designbycurio.com/ja/learn)に各スタイルの平易なガイドがあります。

## Curio の使い方は 3 つ

| | 仕組み | 向いている用途 |
| --- | --- | --- |
| **1 · リンクをコピー** | スタイルを開き、*Hand off to My AI* を押して、リンクをチャットに貼り付けます。インストール不要。リンクは 15 分間、完全な仕様を運びます。 | リンクを開ける AI ならなんでも。最速の方法です。 |
| **2 · MCP で接続** | `https://mcp.designbycurio.com/mcp` をクライアントに追加してサインインします。エージェントはライブラリ全体を検索・閲覧し、仕様を取得できます。 | Claude、Cursor、Codex、ChatGPT、Gemini CLI、VS Code、Kimi、その他あらゆる MCP クライアント。 |
| **3 · スキルをインストール** | スキルをエージェントにクローンします。無料の 105 デザインシステムを同梱し、オフラインでも動作します。 | Claude Code と、スキルフォルダを読めるエージェント。 |

クライアントごとの手順は **[ドキュメント](https://designbycurio.com/ja/docs)** にあります。

>

## 無料と Pro

カタログには **2,233 のデザインシステム** があり、そのうち **105 が無料** です（2026 年 9 月 18 日時点）。新しいスタイルは毎週追加されます。無料アカウントは、どのチャネルでも無料コレクションを利用できます。**Pro** は MCP と共有リンクを通じてライブラリ全体を解放し、月ごとの仕様取得枠が付きます。プランは[料金ページ](https://designbycurio.com/ja/pricing)をご覧ください。

## こんな人のために

AI でものを作っていて、それをデザイナーが手がけたように見せたい人へ。ランディングページ、ピッチデッキ、レポート、ダッシュボード、ポスター、SNS カード。デザインの知識は要りません。好きなスタイルを選び、エージェントに渡して、作業を続けるだけです。
